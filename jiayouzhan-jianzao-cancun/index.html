坎昆加油站建造与改造

加油站 — 土建、储罐、罩棚与场地，尽可能保持营业

加油站是一座受监管的工业设施，只是外表看起来像零售。我们在坎昆承担土建部分——场地、储罐基坑、罩棚、便利店，以及能让改造期间继续营业的施工顺序——而其报批卷宗先是联邦级的，之后才是市政级的。

施工如何划分

  • 储罐基坑与防渗围堰：喀斯特地层开挖、密闭围堰、地下水位高时的抗浮锚固、监测井。
  • 加油区地坪：配筋、坡向隔油池、耐燃油腐蚀并可承受持续重车荷载。
  • 罩棚：按风荷载分区计算的钢结构，防腐体系按实际离海距离确定。
  • 便利店、卫生间与后勤用房，加盟站按品牌形象手册执行。
  • 排水与隔油池：任何排水离场之前先完成油水分离。

卷宗首先是联邦级的

成品油零售在国家层面受监管。站点经营许可由能源监管委员会（CRE）核发，环境与工业安全归属油气行业监管机构 ASEA，而非州政府。市政府核发施工许可，但建立在上述两者之上。

实际操作中，业主或品牌方推进 CRE 与 ASEA 线，我们推进施工线，两条线必须同步。无视 ASEA 顺序的施工计划，最终得到的是一座建成却无法合法售油的站点。

储罐基坑下的喀斯特与地下水

在含溶洞的石灰岩中开挖储罐基坑，与在松散土层中开挖完全不同。溶洞排查不是可选项；地下水位高时储罐必须做抗浮锚固——空罐在被淹基坑中会上浮。

坎昆内陆是最简单的情形：水位深、石灰岩致密。靠近海岸与潟湖，以及通往莫雷洛斯港的走廊带，水位抬升，围堰设计随之改变。具体地块的地基与水位可在分区核查中查看。

加油站项目的成败之处

腐蚀。罩棚钢材、紧固件与加油岛包边长期处于盐雾中。靠海一侧用316不锈钢，内陆采用指定涂装体系，并以书面形式交付维护周期。

标高。场地须从任一点都能排向隔油池，同时保持行车舒适。图纸上设错的坡度，到现场就是积存的含油污水。

工序。储罐、管线、地坪与罩棚相互咬合。顺序一错，就得凿开刚浇好的混凝土去补一条本该先敷设的管线。

不停业改造

加油站的大部分工程是改造，而停业的代价高于工程本身。我们按加油岛分期：一侧营业，另一侧重建；卸油时间与客户动线在第一道围挡设置之前就已确定。市政允许之处安排夜间施工，动火作业则规划在远离储罐区的位置。

造价与合同方式

加油站相当大一部分成本位于地面之下。储罐基坑、围堰、管线与隔油池对预算的影响超过便利店与罩棚，而这部分恰恰取决于地基与地下水位。在这类项目上，没有地质勘察的预算算不上预算。

因此我们分两阶段推进：地质勘察、与报批线核对，并给出带区间的方案造价；随后签订固定总价。改造项目还会增加分期计划，明确哪个加油岛何时停用——这一项直接决定施工期间的营业额损失。

坎昆的地块条件对项目的硬性要求

  • 主管市政: 贝尼托华雷斯市
  • 环境管制: 市政；酒店区由 FONATUR 管辖
  • 地基: 城区石灰岩
  • 地下水位: 内陆埋深大
  • 盐雾侵蚀: 中等

按超级街区分区 — 密度与层数逐块不同。

  • 仅市政流程：进度由市政府决定，而非环境部门。这是本地区最快的情形。
  • 地下水位深：可采用常规基础；若地勘确认，渗水井方案可行。
  • 盐雾侵蚀中等：室外用316不锈钢，室内可用304。

常见问题

你们办理 CRE 与 ASEA 许可吗？

我们负责施工卷宗，并与推进 CRE 与 ASEA 线的一方协同——通常是品牌方或业主的专业顾问。我们保证施工计划与报批顺序相匹配，避免出现站点建成却不能开业的局面。

地下水位高的地块能建吗？

能，采用锚固储罐与按抗浮设计的围堰。造价差异在基坑里，而不在可见部分，因此地质与水位数据必须在报价之前到位。

建一座站点要多久？

内陆条件简单的地块，土建需数月。真正的约束是报批线：施工许可跟在联邦许可之后，因此诚实的答案取决于开工时 CRE 与 ASEA 卷宗处于什么阶段。

改造期间站点能继续营业吗？

通常可以，按加油岛分期推进。分期方案、卸油时段与客户动线在进场前以书面形式确定。

你们能按品牌形象手册施工吗？

可以。我们按加盟规格施工过零售项目，包括 7-Eleven 与 GoMart。手册与市政规章偶有冲突；我们在报批前解决，而不是留到验收现场。
